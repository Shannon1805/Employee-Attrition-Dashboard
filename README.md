# 📊 Employee Attrition Dashboard

## 📌 Overview
This project presents an interactive Employee Attrition Dashboard developed using Microsoft Power BI. It provides insights into employee attrition patterns and workforce demographics through interactive visualizations and KPIs.

## ✨ Features
- Executive Overview
- Workforce Profile
- Attrition Drivers
- Interactive Slicers
- KPI Cards
- Department-wise Analysis
- Job Role Analysis
- Matrix Visualization

## 🛠️ Tools Used
- Microsoft Power BI
- DAX
- CSV Dataset
